# My Tree CCU

Трекер посадок и ухода за деревьями колледжа. Интерфейс работает с Node.js API; посадки и журнал изменений хранятся на сервере в `data/store.json`.

## Запуск

Требуется Node.js 18 или новее. Дополнительные npm-пакеты не нужны.

```powershell
npm start
```

Откройте <http://127.0.0.1:3000>. Для режима перезапуска при изменении кода используйте `npm run dev`.

## API

- `GET /api/health` — проверка доступности сервера.
- `GET /api/trees` — список деревьев и журнал действий.
- `POST /api/trees` — добавить посадку. Обязательные поля: `name`, `plantedBy`, `date` (`YYYY-MM-DD`), `status` (`planted`, `watered` или `established`).
- `PATCH /api/trees/:id/status` — обновить статус дерева.

При первом запуске сервер создаёт файл хранилища с четырьмя демонстрационными посадками. Они помечены в интерфейсе как пример, а не фактическая статистика колледжа. Файл хранилища не включается в Git.

Backend предназначен для локальной демонстрации: он не использует аккаунты и авторизацию, поэтому не публикуйте его в интернете с реальными персональными данными.
